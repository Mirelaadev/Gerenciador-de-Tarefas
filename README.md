# Gerenciador de Tarefas

Projeto desenvolvido com o objetivo de estudar e praticar **React**.

## Tecnologias

* React
* Vite
* JavaScript
* Tailwind CSS
* ESLint

## Objetivo

Este projeto será utilizado para praticar conceitos do React, como:

* Componentes
* JSX
* Props
* Estado (`useState`)
* Eventos
* Renderização condicional
* Listas
* Hooks
* Organização de componentes

## Como executar

Clone o repositório e entre na pasta do projeto:

```bash
cd gerenciador_de_tarefas
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse o endereço exibido no terminal.
